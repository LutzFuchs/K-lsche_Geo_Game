# Die letzte Nachricht des Stadtarchitekten

A mobile-first, GPS-driven scavenger hunt web app for a one-time public event in Munich.

- **Race start:** 17:00 Berlin · 7 July 2026 (configurable)
- **Duration:** 60 minutes, seven outdoor stations from Odeonsplatz to Marienplatz
- **Player-visible copy:** German throughout (riddles, hints, UI, leaderboard)
- **No backend:** state is per-device, but every team races against five seeded rival teams for live competitive feel

The product is a single-use teambuilding game, optimized for reliability and clarity on the day, not long-term maintenance.

---

## Player flow

```
┌────────────┐   ┌────────────┐   ┌────────────┐   ┌────────────┐   ┌────────────┐
│  Step 1    │ → │  Step 2    │ → │  Lobby     │ → │  7 stations│ → │  Final     │
│  Teamname  │   │  Teamfoto  │   │  Countdown │   │  GPS unlock│   │  Podium    │
│            │   │  (camera)  │   │  bis 17:00 │   │  + Riddle  │   │  Leaderb.  │
└────────────┘   └────────────┘   └────────────┘   └────────────┘   └────────────┘
```

Teams can register their name and team photo **any time before the race**. Closing the browser preserves their lobby state. At 17:00 Berlin time the GO button switches from a locked countdown card to a live "Bereit zum Start?" card; tapping it begins the timer.

## Quick Start

```bash
bun install
bun run dev          # http://localhost:5173 (or 5174 if 5173 busy)
bun run build        # static output in dist/
bun run preview      # serves the production build locally
```

The app needs **HTTPS** (or `localhost`) for browser geolocation and camera. Cloud Run, ngrok, and `localhost` all qualify; raw `http://` over Wi-Fi does not.

To test before-race team creation locally, just open the app — you'll see the lobby with a live countdown to 7 July 2026 17:00 Berlin. To test in-game flow before that date, temporarily set `raceStartAt` in `src/config.ts` to a past timestamp.

## Customization (event-day surface)

### `src/config.ts`

```ts
export const finalMeetingPointText = 'TBD'
export const showMeetingPoint = false
export const raceStartAt = new Date('2026-07-07T15:00:00Z') // 17:00 Berlin (CEST = UTC+2)
```

| Field                    | Purpose                                                                 |
| ------------------------ | ----------------------------------------------------------------------- |
| `finalMeetingPointText`  | Venue + address shown on the final card after the last riddle           |
| `showMeetingPoint`       | `false` keeps the placeholder copy; flip to `true` to reveal            |
| `raceStartAt`            | Hard gate — locks the GO button until this UTC moment                   |

If you change `raceStartAt`, double-check the UTC offset:
- **CEST (Apr–Oct):** UTC+2 → `17:00 Berlin = 15:00 UTC`
- **CET (Nov–Mar):** UTC+1 → `17:00 Berlin = 16:00 UTC`

### `src/stations.ts`

Stations are an ordered array driving every screen. Reorder, remove, or insert freely; the app reads `stations.length` and `stations[currentIndex]`, never hard-coded indexes. Each station carries `id, title, locationName, lat, lng, radiusMeters, story, riddle, hint, answer, badge`.

## Game mechanics

### Scoring

Per station: `100 base + speed bonus − hint cost − wrong-attempt cost`.

- **Speed bonus**: up to **+60 pts** at 0 s, decays linearly to 0 over 8 minutes.
- **Hint penalty**: **−25 pts** if the hint is revealed (button labelled with the cost).
- **Wrong attempt**: **−5 pts** for each wrong answer after the first try.

Logic in `src/lib/score.ts`.

### Rival teams (live leaderboard)

Five rival teams (Brezn-Bande, Isar-Wölfe, Maßkrug-Mafia, Glockenspiel-Gang, …) are deterministically seeded from your team name. Each has a per-station solve schedule generated by Mulberry32 PRNG with plausible pace variation (one fast, one slow, one wildcard). Their progress ticks live during the race so the leaderboard genuinely changes every minute.

Rivals are **synthetic**, not networked — different devices each get their own seeded set. The fiction is "your group of rivals." This keeps the experience competitive without needing infra.

Logic in `src/lib/rivals.ts` and `src/lib/leaderboard.ts`.

### Badges

Every solved station awards a German badge: Säule, Kuppel, Pavillon, Krone, Krug, Raute, Löwe. Badges show on the solved card with the points earned and feed the trophy line on the final screen.

### Host manual unlock

Hidden gestures on the **station title**:

- **Long-press** for **1.5 s**, **or**
- **Tap** the title **5 times within 3 s**

Either opens the *Host-Übersteuerung* dialog with a *Manuell freischalten* button. Use only if GPS is failing. Manually unlocked stations are flagged in localStorage (`manuallyUnlocked: true`) for post-event auditing.

## GPS behavior

- Uses `navigator.geolocation.watchPosition` with `enableHighAccuracy: true`, `maximumAge: 5000`, 15 s timeout. Browsers update every 5–10 s when accuracy permits — matching the cadence the brief asked for.
- A 20 s staleness watchdog restarts the watcher if no fix arrives.
- Header HUD shows `GPS · Suche · Aus` so participants can tell at a glance.
- Distances use Haversine (`src/lib/distance.ts`) with WGS-84 mean Earth radius.
- Each station has a generous radius (60–80 m) to absorb urban GPS drift between buildings.

## Deploy to Google Cloud Run

**Full step-by-step in [DEPLOY.md](./DEPLOY.md).** TL;DR:

- **Path A** (one-shot, no GitHub): `gcloud run deploy kope --source . --region europe-west3 --allow-unauthenticated --port 8080 --min-instances 1`
- **Path B** (recommended for event-day edits): GitHub repo → Cloud Build trigger → `git push` ships in ~90 s. Setup is 10 minutes via the Cloud Run console.

For richer cartoon Munich heroes (Midjourney / Imagen prompts + swap-in instructions): see [IMAGES.md](./IMAGES.md).

Below is the standalone Dockerfile / nginx context if you'd rather build images yourself.

---

The bundled `Dockerfile` builds a static bundle with Bun and serves it through nginx, listening on `$PORT` (Cloud Run sets this to `8080`).

```bash
# Build & push (replace PROJECT_ID).
gcloud builds submit --tag gcr.io/PROJECT_ID/kope

# Deploy. --allow-unauthenticated is necessary for participants on phones.
gcloud run deploy kope \
  --image gcr.io/PROJECT_ID/kope \
  --region europe-west3 \
  --platform managed \
  --allow-unauthenticated \
  --port 8080 \
  --min-instances 1
```

`--min-instances 1` keeps one container warm so the first participant doesn't wait for a cold start at 17:00 sharp. Cold-start cost on a 6-MB image is small but non-zero on phones.

Cloud Run gives you HTTPS automatically — that's load-bearing for both `navigator.geolocation` and `getUserMedia` (camera). A `/healthz` endpoint returns `200 ok` for Cloud Run's TCP/HTTP health checks.

### Caching strategy (`deploy/nginx.conf.template`)

- Hashed JS/CSS/image assets: `max-age=2592000, immutable`.
- `index.html`: `no-store, must-revalidate` so a same-day rebuild (e.g. flipping `showMeetingPoint`) reaches participants immediately.

### Updating the meeting point on event day

```bash
# 1. Edit src/config.ts → finalMeetingPointText, showMeetingPoint
# 2. Redeploy
gcloud builds submit --tag gcr.io/PROJECT_ID/kope
gcloud run deploy kope --image gcr.io/PROJECT_ID/kope --region europe-west3
```

Because `index.html` is no-cache, every active participant gets the new text on their next page load.

## Documented assumptions

- **Coordinates are approximate.** Centroids were chosen from common knowledge of central Munich; verify on-site before the event and tighten / loosen `radiusMeters` per station as needed. Stations 1–2 (Odeonsplatz / Theatinerkirche) sit close to one another — order still works because Station 2 is checked only after Station 1 is solved.
- **No backend = no cross-device leaderboard.** Each phone runs its own progress and its own seeded rivals. To get a real cross-team ranking on the day, collect the share-button output from each team at the finish.
- **Photos stay local.** The team photo never leaves the device. Stored as a downscaled (max 720 px edge) JPEG data URL in localStorage; original camera image is discarded after resize. Worst-case storage per device ≈ 250 KB.
- **localStorage quota is per-origin, ~5 MB.** Plenty for the JSON state + one photo.
- **Single-use scope.** No tests, no analytics, no error tracking, no i18n surface beyond German. The app is meant to live for one afternoon.
- **GPS in dense urban areas drifts.** Default radii (60–80 m) intentionally absorb that; in narrow streets or near tall buildings (Marienplatz, Residenz!), consider widening to 80–100 m on the day if walk-tests show false negatives.
- **Browser support.** Targets modern iOS Safari and Chrome on Android. Older devices may struggle with `watchPosition` accuracy or refuse `capture="environment"`; manual unlock + gallery fallback are the safety nets.
- **Race-start gate is client-side.** The lobby trusts `Date.now()` on the device. A participant with a wildly wrong system clock could theoretically start early, but the GPS unlock would still be honest and rivals are scored relative to their own start, so the impact is cosmetic.
